# Chef RPG — Tradução PT-BR

## Instalação manual (sem executar EXE)

1. Feche Chef RPG e a Steam.
2. Na Steam, abra **Gerenciar > Procurar arquivos locais**.
3. Copie a pasta `Chef RPG_Data` deste ZIP para a pasta raiz de Chef RPG.
4. Confirme a substituição de `Chef RPG_Data/resources.assets`.
5. Abra o jogo normalmente pela Steam.

## Requisitos

Não é necessário instalar UABEA, BepInEx, Python ou .NET para jogar.

## Conteúdo

O pacote contém somente `Chef RPG_Data/resources.assets`; não inclui executáveis,
atualizador, UABEA, Python ou .NET. Os arquivos correspondem apenas à versão do
jogo indicada na página do Nexus; não os reutilize após uma atualização da Steam.

## Como desfazer

Use a verificação de integridade de arquivos da Steam para restaurar o original.
