# Texto para a página do Nexus Mods

## Título

Chef RPG — Tradução PT-BR

## Resumo

Tradução para português do Brasil de diálogos, menus, romances, festivais e itens
de Chef RPG.

## Descrição

Este mod substitui somente `Chef RPG_Data/resources.assets`, contendo as cinco
tabelas de localização do jogo. Não requer UABEA, BepInEx, Python ou .NET para
jogar.

Instalação: extraia o ZIP na raiz de Chef RPG e confirme a substituição de
`Chef RPG_Data/resources.assets`. Faça backup ou use a verificação de integridade
da Steam para restaurar o original. Em **Propriedades > Idioma**, mantenha o jogo em
**English**: a tradução substitui a tabela inglesa usada pelo mod.

Este lançamento não inclui os arquivos de cena `level*`; eles não são necessários
para a tradução principal e foram excluídos por segurança.

## Arquivo para enviar

`Chef RPG_Data.zip`
